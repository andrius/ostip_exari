# CLAUDE.md

## Overview

`ostip_exari` is an Elixir client for the Asterisk REST Interface (ARI), generated by `swagger-codegen` from Asterisk's swagger/ARI definitions. Only the Docker and Asterisk configs (used to run codegen against a live Asterisk) are hand-edited; the client code itself is regenerated, not manually maintained. Andrius's own (`andrius/ostip_exari`). Last commit 2018-02-28 - dormant.

## Stack

Elixir (`mix.exs`, `lib/`), swagger-codegen, Docker.
